Resalta el texto de la web con inteligencia

Marks es una extensión para Chrome y Firefox que te permite resaltar y gestionar de forma eficiente el texto importante de las páginas web.

Funciones disponibles

🎨

Resaltado en varios colores

Resalta texto con los 5 colores predeterminados (amarillo, verde, azul, rosa y naranja) y con colores personalizados para clasificar tus contenidos.

⚡

Atajos de teclado

Usa Ctrl+Shift+número para aplicar resaltados rápidamente.

🗺️

Minimapa

Muestra un minimapa en el lado derecho de la página para localizar fácilmente las zonas resaltadas.

☁️

Sincronización

Sincroniza tus resaltados entre varios dispositivos mediante la sincronización nativa del navegador o una copia de seguridad cifrada en la nube.

🌍

Compatible con varios idiomas

Admite distintos idiomas para llegar a más personas.

✨

Gestión sencilla

Edita y elimina resaltados fácilmente con el menú contextual del botón derecho y la interfaz de control.

Demostración

Selecciona un texto y haz clic con el botón derecho, o usa los atajos de teclado, para resaltarlo con el color que quieras.

  • Selecciona texto y haz clic con el botón derecho para elegir un color
  • Haz clic en el icono que aparece tras seleccionar el texto para aplicar el resaltado
  • Usa los atajos Ctrl+Shift+1~4
  • Haz clic en un resaltado para cambiar o añadir colores y para eliminarlo
  • Los resaltados se guardan automáticamente para cada página
  • Consulta la ubicación de los resaltados con el minimapa

Esto es información importante. Puedes distinguir fácilmente el contenido clave de las páginas web.

Muy útil para organizar investigaciones o material de estudio, y los resaltados siguen ahí cuando vuelves a visitarlas.

Instalación sencilla

Instala Marks en solo 3 pasos y empieza a usarlo enseguida.

Instalar desde Chrome Web Store Instalar desde Firefox Add-ons

Paso 1

Busca "Marks: Text Highlighter" en Chrome Web Store o en Firefox Add-ons.

Paso 2

Haz clic en "Añadir a Chrome" o "Añadir a Firefox" para instalar la extensión.

Paso 3

¡Selecciona texto en cualquier página web y empieza a resaltar!
