Destaque o texto da web com inteligência

O Marks é uma extensão para Chrome e Firefox que permite destacar e gerenciar com eficiência os textos importantes das páginas da web.

Recursos disponíveis

🎨

Destaque em várias cores

Destaque textos com as 5 cores padrão (amarelo, verde, azul, rosa e laranja) e com cores personalizadas para classificar seu conteúdo.

⚡

Atalhos de teclado

Use Ctrl+Shift+número para aplicar destaques rapidamente.

🗺️

Minimapa

Exibe um minimapa no lado direito da página para localizar facilmente as áreas destacadas.

☁️

Sincronização

Sincronize seus destaques entre vários dispositivos pela sincronização nativa do navegador ou por um backup criptografado na nuvem.

🌍

Suporte a vários idiomas

Compatível com diversos idiomas para alcançar mais pessoas.

✨

Gerenciamento fácil

Edite e exclua destaques com facilidade pelo menu de contexto do botão direito e pela interface de controle.

Demonstração

Selecione um texto e clique com o botão direito, ou use os atalhos de teclado, para destacá-lo com a cor que quiser.

  • Selecione o texto e clique com o botão direito para escolher uma cor
  • Clique no ícone que aparece após selecionar o texto para aplicar o destaque
  • Use os atalhos Ctrl+Shift+1~4
  • Clique em um destaque para alterar ou adicionar cores e para excluí-lo
  • Os destaques são salvos automaticamente para cada página
  • Veja onde estão os destaques pelo minimapa

Esta é uma informação importante. Você consegue distinguir facilmente o conteúdo principal das páginas da web.

Muito útil para organizar pesquisas ou materiais de estudo, e os destaques continuam lá quando você visita de novo.

Instalação simples

Instale o Marks em apenas 3 passos e comece a usar na hora.

Instalar pela Chrome Web Store Instalar pelo Firefox Add-ons

Passo 1

Procure por "Marks: Text Highlighter" na Chrome Web Store ou no Firefox Add-ons.

Passo 2

Clique em "Usar no Chrome" ou "Adicionar ao Firefox" para instalar a extensão.

Passo 3

Selecione um texto em qualquer página da web e comece a destacar!
