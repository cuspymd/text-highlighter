Marks: Text Highlighter User Guide

Thank you for using Marks: Text Highlighter. This extension allows you to easily highlight, save, and manage text on web pages.

Note A short getting-started guide is also built into the extension. Open it from the "View Usage Guide" button on the settings screen, or from the "See the full guide" link that appears in the popup when the page has no highlights yet.

How to Add Highlights

There are three ways to add highlights to selected text on a web page.

1. Using Control UI

When you select text, a highlight icon (pen shape) appears near the selection. Click this icon or hover over it to reveal the Control UI with a color palette. Click a color to apply the highlight.

Note This works when 'Show Control UI on text selection' is enabled in settings. It is also the primary method for mobile devices.

2. Using Context Menu

Select text and right-click to open the context menu. Navigate to "Marks: Text Highlighter" and select a color to highlight.

Limitation Context menu highlighting is not supported on Firefox for Android.

3. Using Shortcuts

Select text and use keyboard shortcuts to quickly apply colors. There are 5 shortcut slots, and you can choose which color each slot uses on the settings screen.

  • Ctrl + Shift + 1 : Slot 1 (Default: Yellow)
  • Ctrl + Shift + 2 : Slot 2 (Default: Green)
  • Ctrl + Shift + 3 : Slot 3 (Default: Blue)
  • Ctrl + Shift + 4 : Slot 4 (Default: Pink)
  • Slot 5 (Default: Orange) : has no key combination assigned by default. Assign one yourself in the browser's shortcut settings before it will work.
Note On macOS the combination is Command + Shift + number. The key combinations themselves are changed in the browser's shortcut settings (Chrome: chrome://extensions/shortcuts, Firefox: about:addons).
Limitation Shortcuts are not supported on Firefox for Android.

How to Delete Highlights

You can remove unnecessary highlights using the following methods:

  • Individual Delete (Control UI): Click on an existing highlight to open the Control UI. Click the Trash icon to delete it.
  • Individual Delete (Popup): Click the extension icon in the toolbar to open the Popup menu. In the "Current Page Highlights" list, click the X button next to the item you want to remove.
  • Clear Page (Popup): Click the "Delete All Highlights" button at the bottom of the Popup menu to remove all highlights on the current page.
  • Delete Page (Pages List): In the Highlighted Pages List dashboard, click the "Delete" button on a specific page card to remove all data for that page.
  • Delete All Data (Pages List): Click the Trash icon (Delete All Pages) in the top toolbar of the dashboard to delete all saved highlight data.

Custom Colors

Adding and Changing Colors

You can add your own colors in addition to the 5 default ones (Yellow, Green, Blue, Pink, Orange). Add them straight from the page, or manage them on the settings screen.

  1. Click on an existing highlight to open the Control UI.
  2. Click the + button at the end of the color list.
  3. Pick a color from the selector and click "Apply".
Note The + button does not appear in the Control UI when highlighting new text. It only appears when you click on an already created highlight.

Managing Colors in Settings

Colors you add are managed in the "Custom Colors" section of the settings screen (popup's settings (⚙) icon → Custom Colors).

  • Add: Use the "+ Add Custom Color" button to open the color picker.
  • Rename: Click a color's name to edit it in place.
  • Change color: Use the "Edit" button. Highlights already painted with that color are not affected.
  • Delete one: Each color has its own "Remove" button.
  • Delete all: The "Remove All" button at the top right of the section deletes every added color, leaving the 5 defaults.

Minimap

A Minimap is displayed on the right side of web pages that have highlights.

  • The minimap visually indicates the location of highlights relative to the entire page length.
  • Clicking a marker on the minimap instantly scrolls to that highlight's position.
  • You can hide it by turning off the "Show Minimap" switch on the settings screen.

Popup Menu

The menu that appears when you click the Marks icon in the browser toolbar.

  • Settings (⚙) icon: The gear at the top right opens the settings screen. Options such as the minimap, the control UI and one-click highlighting all live there.
  • Current Page Highlights: The highlights saved on the page you are viewing. Click an entry to jump to it, or use the X button at its top right to delete that one.
  • Highlighted Pages List: Opens the dashboard screen to manage all saved pages.
  • Delete All Highlights: Removes every highlight on the current page. The button is disabled when there is nothing to delete.
When an entry says "Not found on this page" If the page rendered late or its content changed, a highlight's position may not be restored. That entry is then dimmed and a "Search again" button appears; pressing it asks the page to look for the highlight once more. If it still cannot be found, the page content really has changed. The stored highlight data itself is not deleted.

Settings Screen

Open it with the settings (⚙) icon at the top right of the popup. The switches and buttons that used to sit in the popup have all moved here.

General

  • Show Minimap: Toggles the display of the minimap on the right side of the page.
  • Show Control UI on Text Selection: Toggles whether the highlighter icon automatically appears when you select text.
  • One-Click Highlight: When on, pressing the selection icon highlights straight away in the color you used last, without opening the palette. Off by default; to use a different color, click the highlight it creates and pick from the palette.
Note One-click highlighting needs the selection icon to exist, so while "Show Control UI on Text Selection" is off this row is dimmed and cannot be used.

Custom Colors

Rename a color, change its color, and delete colors one at a time or all at once. See Custom Colors for details.

Cloud Sync (Beta)

Issue a sync code, pair devices, and sync on demand. See Cloud Sync (Beta) for details.

Shortcut Colors

Choose which color each of the 5 shortcut slots applies. The defaults for slots 1-5 are Yellow, Green, Blue, Pink and Orange, and custom colors can be assigned too. The key combinations themselves are changed in the browser's shortcut settings.

Help

The "View Usage Guide" button opens the getting-started guide built into the extension.

Highlighted Pages List

A dashboard where you can view and manage all saved highlight information at a glance.

  • Search: Search saved records by page title or URL. Matching text is highlighted in the results.
  • Sort: Sort the list by newest, oldest, etc.
  • Expand/Collapse All: Click the toolbar button to expand or collapse the highlight details of all visible pages at once. The button switches between "Expand all" and "Collapse all" depending on the current state.
  • Delete: Delete individual pages or use the top toolbar button to clear all data.
  • Export/Import: Backup or restore your data via the More actions (…) menu in the toolbar.

Synchronization

Syncs highlight data across devices via your logged-in Google (Chrome) or Firefox account.

How it Works

Adding or deleting highlights on one device automatically reflects on other devices logged in with the same account. In case of data conflicts, the most recent change is preserved.

Limitations

  • Storage Limit: Sync storage has a total limit of 100KB, and a single highlight item cannot exceed 8KB.
  • Eviction Policy: When storage is full, sync data for the oldest updated pages is automatically removed to make space. (Local data is preserved.)
  • Mobile Unsupported: Sync is not supported on Firefox for Android.

Cloud Sync (Beta)

A separate feature for environments that don't support browser-native sync, such as Firefox for Android. Devices are linked using a sync code instead of an account login, and highlight data is encrypted on your device before upload, so the server never has access to the actual content.

How to Use

  1. Click the extension icon in the toolbar to open the Popup, then click the Settings (⚙) icon.
  2. In the "Cloud Sync (Beta)" section of the Settings screen, click "Generate New Code" to create a sync code.
  3. On the other device you want to sync, open the Settings screen and enter the same code in the "Enter sync code from another device" field, then click "Connect".
  4. Turn on the "Cloud Sync" switch on each device to activate syncing. The extension syncs automatically about every 15 minutes, or you can click "Sync Now" to sync immediately.
Caution If you lose your sync code, data backed up to the cloud cannot be recovered. The code is partially masked on screen by default — use "Show" to reveal it in full or "Copy" to copy it to the clipboard. Keep it stored somewhere safe.

Disconnecting: Clicking "Forget Code" in the Settings screen disconnects sync on this device and forgets the sync code.

Note Using browser-native sync and Cloud Sync at the same time is not guaranteed to work correctly. We recommend using only one of the two.

Import & Export

Useful for safely backing up data or moving to another browser.

  • Export: Download all currently saved highlight data as a JSON file.
  • Import: Restore data by selecting a previously exported JSON file.
