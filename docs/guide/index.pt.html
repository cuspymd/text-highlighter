Guia de uso do Marks: Text Highlighter

Obrigado por usar o Marks: Text Highlighter. Esta extensão permite destacar, salvar e gerenciar textos em páginas da web de forma fácil e rápida.

Observação A extensão também traz um guia rápido de primeiros passos. Você pode abri-lo pelo botão "Ver guia de uso" na tela de configurações, ou pelo link "Ver o guia completo" que aparece no menu pop-up quando a página ainda não tem destaques.

Como adicionar destaques

Há três maneiras de destacar o texto que você seleciona em uma página da web.

1. Com a interface de controle

Ao selecionar um texto, aparece um ícone de marca-texto (em formato de caneta) ao lado da seleção. Clique no ícone ou passe o mouse sobre ele para exibir a interface de controle com a paleta de cores. Clique em uma cor para aplicar o destaque.

Observação Funciona quando a opção "Mostrar interface de controle ao selecionar texto" está ativada nas configurações. Também é o método principal em dispositivos móveis.

2. Com o menu de contexto

Selecione o texto e clique com o botão direito para abrir o menu de contexto. Em "Marks: Text Highlighter", escolha uma cor para destacar.

Limitação Destacar pelo menu de contexto não é compatível com o Firefox para Android.

3. Com atalhos de teclado

Selecione o texto e use um atalho de teclado para aplicar uma cor rapidamente. São 5 espaços de atalho, e você pode escolher qual cor cada um usa na tela de configurações.

  • Ctrl + Shift + 1 : Espaço 1 (padrão: amarelo)
  • Ctrl + Shift + 2 : Espaço 2 (padrão: verde)
  • Ctrl + Shift + 3 : Espaço 3 (padrão: azul)
  • Ctrl + Shift + 4 : Espaço 4 (padrão: rosa)
  • Espaço 5 (padrão: laranja) : não vem com nenhuma combinação de teclas atribuída. Você precisa defini-la nas configurações de atalhos do navegador para que funcione.
Observação No macOS a combinação é Command + Shift + número. As combinações de teclas em si são alteradas nas configurações de atalhos do navegador (Chrome: chrome://extensions/shortcuts, Firefox: about:addons).
Limitação Os atalhos de teclado não são compatíveis com o Firefox para Android.

Como excluir destaques

Você pode remover os destaques desnecessários das seguintes formas:

  • Excluir um (interface de controle): clique em um destaque existente para abrir a interface de controle e clique no ícone de lixeira.
  • Excluir um (menu pop-up): clique no ícone da extensão na barra de ferramentas para abrir o menu pop-up. Na lista "Destaques da página atual", clique no botão X ao lado do item que deseja remover.
  • Limpar a página (menu pop-up): clique no botão "Excluir todos os destaques" na parte inferior do menu pop-up para remover todos os destaques da página atual.
  • Excluir uma página (lista de páginas): no painel de páginas destacadas, clique no botão "Excluir" de um cartão de página para apagar todos os dados dela.
  • Excluir todos os dados (lista de páginas): clique no ícone de lixeira (Excluir todas as páginas) na barra superior do painel para apagar todos os dados de destaque salvos.

Cores personalizadas

Adicionar e alterar cores

Além das 5 cores padrão (amarelo, verde, azul, rosa e laranja), você pode adicionar as suas próprias. É possível adicioná-las direto da página ou gerenciá-las na tela de configurações.

  1. Clique em um destaque existente para abrir a interface de controle.
  2. Clique no botão + no fim da lista de cores.
  3. Escolha uma cor no seletor e clique em "Aplicar".
Observação O botão + não aparece na interface de controle quando você destaca um texto novo. Ele só aparece ao clicar em um destaque já criado.

Gerenciar nas configurações

As cores que você adiciona são gerenciadas na seção "Cores personalizadas" da tela de configurações (ícone de configurações (⚙) do menu pop-up → Cores personalizadas).

  • Adicionar: use o botão "+ Adicionar cor" para abrir o seletor de cores.
  • Renomear: clique no nome de uma cor para editá-lo ali mesmo.
  • Alterar a cor: use o botão "Alterar". Os destaques já aplicados com aquela cor não são afetados.
  • Excluir uma: cada cor tem o seu próprio botão "Excluir".
  • Excluir todas: o botão "Excluir tudo", no canto superior direito da seção, apaga todas as cores adicionadas e mantém apenas as 5 padrão.

Minimapa

Do lado direito das páginas da web que têm destaques é exibido um minimapa.

  • O minimapa mostra visualmente onde estão os destaques em relação ao comprimento total da página.
  • Ao clicar em um marcador do minimapa, a página rola imediatamente até aquele destaque.
  • Você pode ocultá-lo desativando a chave "Mostrar minimapa" na tela de configurações.

Menu pop-up

É o menu que aparece ao clicar no ícone do Marks na barra de ferramentas do navegador.

  • Ícone de configurações (⚙): a engrenagem no canto superior direito abre a tela de configurações. Opções como o minimapa, a interface de controle e o destaque com um clique ficam todas lá.
  • Destaques da página atual: os destaques salvos na página que você está vendo. Clique em um item para ir até ele, ou use o botão X no canto superior direito dele para excluí-lo.
  • Lista de páginas destacadas: abre o painel onde todas as páginas salvas são gerenciadas.
  • Excluir todos os destaques: remove todos os destaques da página atual. O botão fica desativado quando não há nada a excluir.
Quando um item diz "Não encontrado nesta página" Se a página demorou a ser renderizada ou o conteúdo dela mudou, a posição de um destaque pode não ser restaurada. Esse item fica esmaecido e surge um botão "Procurar de novo"; ao pressioná-lo, a página procura o destaque mais uma vez. Se ainda assim não for encontrado, é porque o conteúdo da página realmente mudou. Os dados do destaque salvo não são apagados.

Tela de configurações

Abre pelo ícone de configurações (⚙) no canto superior direito do menu pop-up. As chaves e os botões que antes ficavam no menu pop-up foram todos movidos para cá.

Geral

  • Mostrar minimapa: ativa ou desativa o minimapa no lado direito da página.
  • Mostrar interface de controle ao selecionar texto: ativa ou desativa a exibição automática do ícone de marca-texto ao selecionar um texto.
  • Destaque com um clique: quando ativado, pressionar o ícone de seleção destaca imediatamente com a última cor usada, sem abrir a paleta. Vem desativado por padrão; para usar outra cor, clique no destaque criado e escolha na paleta.
Observação O destaque com um clique depende da existência do ícone de seleção, então enquanto "Mostrar interface de controle ao selecionar texto" estiver desativado, esta linha fica esmaecida e não pode ser usada.

Cores personalizadas

Permite renomear uma cor, alterar o tom dela e excluir cores uma a uma ou todas de uma vez. Veja Cores personalizadas para mais detalhes.

Sincronização na nuvem (Beta)

Aqui você gera o código de sincronização, vincula dispositivos e sincroniza na hora. Veja Sincronização na nuvem (Beta) para mais detalhes.

Cores dos atalhos

Escolha qual cor cada um dos 5 espaços de atalho aplica. Os padrões dos espaços 1 a 5 são amarelo, verde, azul, rosa e laranja, e cores personalizadas também podem ser atribuídas. As combinações de teclas em si são alteradas nas configurações de atalhos do navegador.

Ajuda

O botão "Ver guia de uso" abre o guia de primeiros passos incluído na extensão.

Lista de páginas destacadas

Um painel onde você vê e gerencia num relance todas as informações de destaque salvas.

  • Buscar: pesquise os registros salvos por título da página ou URL. O texto correspondente fica realçado nos resultados.
  • Ordenar: ordene a lista por mais recente, mais antigo etc.
  • Expandir/recolher tudo: clique no botão da barra de ferramentas para expandir ou recolher de uma vez os detalhes dos destaques de todas as páginas visíveis. O botão alterna entre "Expandir tudo" e "Recolher tudo" conforme o estado atual.
  • Excluir: exclua páginas individuais ou use o botão da barra superior para apagar todos os dados.
  • Exportar/importar: faça backup ou restaure seus dados pelo menu Mais ações (…) da barra de ferramentas.

Sincronização

Sincroniza os dados de destaque entre dispositivos por meio da sua conta Google (Chrome) ou Firefox conectada.

Como funciona

Ao adicionar ou excluir destaques em um dispositivo, a alteração é refletida automaticamente nos outros dispositivos conectados com a mesma conta. Em caso de conflito, a alteração mais recente é mantida.

Limitações

  • Limite de armazenamento: o armazenamento de sincronização tem um limite total de 100 KB, e um único destaque não pode passar de 8 KB.
  • Limpeza de dados antigos: quando o armazenamento enche, os dados sincronizados das páginas atualizadas há mais tempo são removidos automaticamente para abrir espaço. (Os dados locais são preservados.)
  • Sem suporte no celular: a sincronização não é compatível com o Firefox para Android.

Sincronização na nuvem (Beta)

Um recurso à parte para ambientes que não têm a sincronização nativa do navegador, como o Firefox para Android. Os dispositivos são vinculados por um código de sincronização em vez de login com conta, e os dados de destaque são criptografados no seu dispositivo antes do envio, de modo que o servidor nunca tem acesso ao conteúdo real.

Como usar

  1. Clique no ícone da extensão na barra de ferramentas para abrir o menu pop-up e clique no ícone de configurações (⚙).
  2. Na seção "Sincronização na nuvem (Beta)" da tela de configurações, clique em "Gerar novo código" para criar um código de sincronização.
  3. No outro dispositivo que você quer sincronizar, abra a tela de configurações, digite o mesmo código no campo "Digite o código de sincronização de outro dispositivo" e clique em "Conectar".
  4. Ative a chave "Sincronização na nuvem" em cada dispositivo para iniciar a sincronização. A partir daí ela ocorre automaticamente a cada 15 minutos, mais ou menos, ou você pode clicar em "Sincronizar agora" para sincronizar na hora.
Atenção Se você perder o código de sincronização, os dados salvos na nuvem não poderão ser recuperados. O código aparece parcialmente oculto na tela; use "Mostrar" para vê-lo por inteiro ou "Copiar" para copiá-lo para a área de transferência. Guarde-o em um lugar seguro.

Desconectar: ao clicar em "Esquecer código" na tela de configurações, este dispositivo é desvinculado da sincronização e esquece o código.

Observação Não há garantia de funcionamento correto ao usar a sincronização nativa do navegador e a sincronização na nuvem ao mesmo tempo. Recomendamos usar apenas uma das duas.

Importar e exportar

Útil para fazer um backup seguro dos dados ou migrá-los para outro navegador.

  • Exportar: baixa todos os dados de destaque salvos como um arquivo JSON.
  • Importar: restaura os dados selecionando um arquivo JSON exportado anteriormente.
