Marks: Text Highlighter 사용 가이드

Marks: Text Highlighter를 사용해 주셔서 감사합니다. 이 확장은 웹페이지의 텍스트를 쉽고 빠르게 하이라이트하고, 저장 및 관리할 수 있는 도구입니다.

참고 확장 안에도 짧은 시작 가이드가 들어 있습니다. 설정 화면의 "사용법 보기" 버튼, 또는 팝업에 하이라이트가 하나도 없을 때 나타나는 "사용법 자세히 보기" 링크로 열 수 있습니다.

하이라이트 추가 방법

웹페이지에서 텍스트를 선택하여 하이라이트를 추가할 수 있는 세 가지 방법이 있습니다.

1. 컨트롤 UI 이용

텍스트를 선택하면 선택 영역 근처에 하이라이트 아이콘(펜 모양)이 나타납니다. 이 아이콘을 클릭하거나 마우스를 올리면 색상 팔레트가 포함된 컨트롤 UI가 표시됩니다. 원하는 색상을 클릭하면 하이라이트가 적용됩니다.

참고 모바일 환경이나 설정에서 '텍스트 선택 시 컨트롤 UI 표시'가 켜져 있어야 작동합니다.

2. 컨텍스트 메뉴 이용

텍스트를 선택한 후 마우스 오른쪽 버튼을 클릭하여 컨텍스트 메뉴를 엽니다. "Marks: Text Highlighter" 메뉴 하위에서 색상을 선택하여 하이라이트할 수 있습니다.

제약 사항 Firefox Android 버전에서는 컨텍스트 메뉴를 통한 하이라이트 추가가 지원되지 않습니다.

3. 단축키 사용

텍스트를 선택한 후 키보드 단축키를 눌러 빠르게 색상을 적용할 수 있습니다. 단축키 슬롯은 5개이며, 각 슬롯에 어떤 색을 쓸지는 설정 화면에서 바꿀 수 있습니다.

  • Ctrl + Shift + 1 : 슬롯 1 (기본: 노란색)
  • Ctrl + Shift + 2 : 슬롯 2 (기본: 초록색)
  • Ctrl + Shift + 3 : 슬롯 3 (기본: 파란색)
  • Ctrl + Shift + 4 : 슬롯 4 (기본: 분홍색)
  • 슬롯 5 (기본: 주황색) : 기본 키 조합이 지정되어 있지 않습니다. 브라우저 단축키 설정에서 직접 지정해야 동작합니다.
참고 macOS에서는 Command + Shift + 숫자키입니다. 키 조합 자체는 브라우저 단축키 설정에서 변경합니다 (Chrome: chrome://extensions/shortcuts, Firefox: about:addons).
제약 사항 Firefox Android 버전에서는 단축키 기능이 지원되지 않습니다.

하이라이트 삭제 방법

불필요한 하이라이트는 다음 방법으로 삭제할 수 있습니다.

  • 개별 삭제 (컨트롤 UI): 이미 하이라이트된 텍스트를 클릭하면 컨트롤 UI가 나타납니다. 여기서 휴지통 아이콘을 클릭하여 삭제합니다.
  • 개별 삭제 (Popup): 브라우저 툴바의 확장 아이콘을 눌러 Popup 메뉴를 엽니다. "현재 페이지 하이라이트" 목록에서 삭제하려는 항목 옆의 X 버튼을 누릅니다.
  • 페이지 내 전체 삭제 (Popup): Popup 메뉴 하단의 "이 페이지의 모든 하이라이트 삭제" 버튼을 누르면 현재 보고 있는 페이지의 모든 하이라이트가 제거됩니다.
  • 페이지 단위 삭제 (Pages List): 하이라이트 목록 화면에서 특정 페이지 카드의 "삭제" 버튼을 누르면 해당 페이지의 모든 데이터가 삭제됩니다.
  • 모든 데이터 삭제 (Pages List): 하이라이트 목록 화면 상단의 휴지통 아이콘(모든 페이지 삭제)을 누르면 저장된 모든 하이라이트 데이터가 삭제됩니다.

사용자 정의 색상 설정

색상 추가 및 변경

기본 5가지 색상(노란색, 초록색, 파란색, 분홍색, 주황색) 외에 나만의 색상을 추가할 수 있습니다. 페이지에서 바로 추가하거나, 설정 화면에서 관리할 수 있습니다.

  1. 이미 하이라이트된 텍스트를 클릭하여 컨트롤 UI를 엽니다.
  2. 색상 목록 끝에 있는 + 버튼을 클릭합니다.
  3. 색상 선택기에서 원하는 색상을 고르고 "적용"을 누릅니다.
주의 새로운 텍스트를 하이라이트할 때 나타나는 컨트롤 UI에는 + 버튼이 표시되지 않습니다. 이미 생성된 하이라이트를 클릭했을 때만 색상 추가 버튼이 나타납니다.

설정 화면에서 관리

추가한 색상은 설정 화면의 "사용자 정의 색상" 섹션에서 관리합니다. (팝업의 설정(⚙) 아이콘 → 사용자 정의 색상)

  • 추가: "+ 색상 추가" 버튼으로 색상 선택기를 열어 추가합니다.
  • 이름 변경: 색상 이름을 클릭하면 그 자리에서 이름을 고칠 수 있습니다.
  • 색상 변경: "변경" 버튼으로 색을 바꿉니다. 이미 칠해진 기존 하이라이트에는 영향을 주지 않습니다.
  • 개별 삭제: 색상마다 있는 "삭제" 버튼으로 하나씩 지울 수 있습니다.
  • 전체 삭제: 섹션 오른쪽 위의 "모두 삭제" 버튼을 누르면 기본 5가지 색상을 제외한 추가 색상이 모두 삭제됩니다.

미니맵 (Minimap)

하이라이트가 있는 웹페이지의 우측에는 미니맵이 표시됩니다.

  • 미니맵은 페이지 전체 길이에서 하이라이트된 위치를 시각적으로 보여줍니다.
  • 미니맵의 색상 마커를 클릭하면 해당 하이라이트 위치로 즉시 스크롤됩니다.
  • 설정 화면의 "미니맵 표시" 스위치를 꺼서 숨길 수 있습니다.

Popup 메뉴 설명

브라우저 툴바의 Marks 아이콘을 클릭하면 나타나는 메뉴입니다.

  • 설정(⚙) 아이콘: 오른쪽 위의 톱니바퀴를 누르면 설정 화면이 열립니다. 미니맵, 컨트롤 UI, 원클릭 하이라이트 같은 옵션은 모두 이곳에 있습니다.
  • 현재 페이지 하이라이트: 현재 보고 있는 페이지에 저장된 하이라이트 목록입니다. 항목을 클릭하면 해당 위치로 이동하고, 오른쪽 위 X 버튼으로 개별 삭제합니다.
  • 하이라이트된 페이지 목록: 저장된 모든 페이지를 관리하는 대시보드 화면을 엽니다.
  • 이 페이지의 모든 하이라이트 삭제: 현재 페이지의 하이라이트를 모두 지웁니다. 지울 하이라이트가 없으면 버튼이 비활성화됩니다.
"이 페이지에서 찾을 수 없음"이 보일 때 페이지 내용이 늦게 그려지거나 바뀌어 하이라이트 위치를 복원하지 못하면, 목록의 해당 항목이 흐리게 표시되면서 "다시 찾기" 버튼이 나타납니다. 이 버튼을 누르면 페이지에서 한 번 더 찾아봅니다. 그래도 찾지 못하면 페이지 내용이 실제로 바뀐 경우입니다. 저장된 하이라이트 데이터 자체는 지워지지 않습니다.

설정 화면

팝업 오른쪽 위의 설정(⚙) 아이콘을 누르면 열립니다. 예전에 팝업에 있던 스위치와 버튼은 모두 이 화면으로 옮겨졌습니다.

일반

  • 미니맵 표시: 페이지 우측 미니맵의 표시 여부를 설정합니다.
  • 텍스트 선택 시 컨트롤 UI 표시: 텍스트를 드래그했을 때 하이라이터 아이콘이 자동으로 나타나는 기능을 켜고 끕니다.
  • 원클릭 하이라이트: 켜면 선택 아이콘을 누르는 순간 팔레트를 열지 않고 마지막에 사용한 색으로 바로 하이라이트됩니다. 기본값은 꺼짐이며, 다른 색을 쓰려면 만들어진 하이라이트를 클릭해 팔레트에서 고릅니다.
참고 원클릭 하이라이트는 선택 아이콘이 있어야 동작하므로, "텍스트 선택 시 컨트롤 UI 표시"가 꺼져 있으면 이 항목은 흐리게 표시되고 사용할 수 없습니다.

사용자 정의 색상

추가한 색상의 이름 변경, 색 변경, 개별 삭제와 전체 삭제를 할 수 있습니다. 자세한 내용은 사용자 정의 색상 설정을 참고하세요.

클라우드 동기화 (베타)

동기화 코드 발급과 기기 연결, 즉시 동기화를 다룹니다. 자세한 내용은 클라우드 동기화 (베타)를 참고하세요.

단축키 색상 지정

단축키 슬롯 5개에 각각 어떤 색을 쓸지 고를 수 있습니다. 기본값은 슬롯 1~5 순서대로 노란색, 초록색, 파란색, 분홍색, 주황색이며, 사용자 정의 색상도 지정할 수 있습니다. 키 조합 자체는 브라우저 단축키 설정에서 변경합니다.

도움말

"사용법 보기" 버튼으로 확장에 내장된 시작 가이드를 엽니다.

하이라이트 목록 (Pages List) 화면

저장된 모든 하이라이트 정보를 한눈에 보고 관리할 수 있는 대시보드입니다.

  • 검색: 페이지 제목이나 URL로 저장된 기록을 검색할 수 있습니다. 검색어와 일치하는 텍스트는 결과에서 강조 표시됩니다.
  • 정렬: 최신순, 오래된순 등으로 목록을 정렬합니다.
  • 모두 펼치기/접기: 툴바 버튼을 클릭하면 현재 표시 중인 모든 페이지의 하이라이트 상세 영역을 한 번에 펼치거나 접을 수 있습니다. 버튼은 현재 상태에 따라 "모두 펼치기"와 "모두 접기"로 전환됩니다.
  • 삭제: 개별 페이지를 삭제하거나, 상단 툴바의 삭제 버튼으로 전체 데이터를 초기화할 수 있습니다.
  • 내보내기/가져오기: 툴바의 더보기(…) 메뉴에서 데이터를 백업하거나 복원할 수 있습니다.

동기화 (Synchronization)

로그인된 구글 계정(Chrome) 또는 Firefox 계정을 통해 여러 기기 간에 하이라이트 데이터를 동기화합니다.

동작 방식

한 기기에서 하이라이트를 추가하거나 삭제하면, 같은 계정으로 로그인된 다른 기기에도 자동으로 반영됩니다. 데이터 충돌 시 가장 최근에 수정된 내용이 유지됩니다.

제약 사항

  • 용량 제한: 동기화 저장소는 총 100KB의 용량 제한이 있으며, 하이라이트 항목 하나당 8KB를 넘을 수 없습니다.
  • 오래된 데이터 정리: 용량이 가득 차면, 가장 오래전에 업데이트된 페이지의 동기화 데이터부터 자동으로 삭제됩니다. (로컬 데이터는 유지됩니다.)
  • 모바일 미지원: Firefox Android 버전에서는 동기화 기능이 지원되지 않습니다.

클라우드 동기화 (베타)

Firefox for Android처럼 브라우저 자체 동기화를 지원하지 않는 환경을 위해 별도로 제공되는 기능입니다. 계정 로그인 없이 동기화 코드만으로 기기를 연결하며, 하이라이트 데이터는 업로드 전에 기기에서 암호화되어 서버는 실제 내용을 알 수 없습니다.

사용 방법

  1. 브라우저 툴바의 확장 아이콘을 클릭해 Popup을 열고, 설정(⚙) 아이콘을 클릭합니다.
  2. 설정 화면의 "클라우드 동기화 (베타)" 섹션에서 "새 코드 생성" 버튼을 눌러 동기화 코드를 발급받습니다.
  3. 동기화할 다른 기기의 설정 화면에서 "다른 기기의 동기화 코드 입력" 칸에 같은 코드를 입력하고 "연결" 버튼을 누릅니다.
  4. 각 기기에서 "클라우드 동기화" 스위치를 켜면 동기화가 활성화됩니다. 이후 약 15분마다 자동으로 동기화되며, "지금 동기화" 버튼으로 즉시 동기화할 수도 있습니다.
주의 동기화 코드를 분실하면 클라우드에 백업된 데이터를 복구할 수 없습니다. 코드는 화면에 일부만 표시(마스킹)되며, "표시" 버튼으로 전체를 확인하거나 "복사" 버튼으로 클립보드에 복사할 수 있습니다. 안전한 곳에 별도로 보관하세요.

연결 해제: 설정 화면의 "코드 초기화" 버튼을 누르면 이 기기의 동기화 연결이 해제되고 동기화 코드를 잊어버립니다.

참고 브라우저 자체 동기화와 클라우드 동기화를 동시에 사용할 경우의 동작은 보장되지 않습니다. 두 기능 중 하나만 사용하는 것을 권장합니다.

가져오기 및 내보내기

데이터를 안전하게 백업하거나 다른 브라우저로 이동할 때 유용합니다.

  • 내보내기 (Export): 현재 저장된 모든 하이라이트 데이터를 JSON 파일로 다운로드합니다.
  • 가져오기 (Import): 이전에 내보낸 JSON 파일을 선택하여 데이터를 복원합니다.
