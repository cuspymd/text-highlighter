Cloud Sync (Beta)

Sync highlights across devices via an encrypted cloud backup, for platforms (like Firefox for Android) where browser sync isn't available. Your data is encrypted on this device before upload; the sync code is the only way to decrypt it.

Your Sync Code

Save this code somewhere safe. If you lose it, this data cannot be recovered.
